# Yurich Connect Для Android TV

Отдельный вариант `tv` использует VPN-ядро, подписки, защищённое хранилище,
Smart Route, Auto DNS и нативное восстановление соединения мобильного клиента.
Телефонный интерфейс остаётся вариантом по умолчанию.

## Совместимость

- Android TV / Google TV, Android 7.0 (API 24) или новее; целевое устройство
  пользователя: MVX01A, Android TV 11. Фотография не определяет архитектуру CPU.
- Один ARM APK включает `armeabi-v7a` и `arm64-v8a`.
- На конкретной прошивке должны быть доступны Android VpnService, установка APK
  и системное разрешение на VPN. Наличие Android не гарантирует эти возможности
  на закрытых операторских приставках или YaOS.
- Получены фотографии лаунчера, профилей, импорта и настроек на физической
  приставке. Это не заменяет проверку внешнего интернета и фоновой работы.

## Интерфейс

Горизонтальный экран с отступами 5% для overscan, видимым фокусом пульта и ленивым
списком профилей. Стрелки перемещают фокус, OK/Enter активирует выделенный элемент.
В списке стрелки вверх/вниз прокручивают профили, включая ещё не отрисованные.
«Назад» закрывает импорт или возвращает из настроек/логов к профилям. Выход из
интерфейса не вызывает отключение VPN.

Подписка добавляется через кнопку ссылки: экранная клавиатура либо явное действие
«Вставить» из буфера обмена. Импорт ограничен 16 384 символами для защиты TV UI;
URL подписки загружается обычным ограниченным импортёром. На TV нет сканера QR
и разрешения камеры. В APK не встроены подписки или учётные данные пользователя.

Настройки включают Smart Route, Auto DNS, язык, ссылку на GitHub Releases и
политику конфиденциальности. Логи включаются только при открытии соответствующего
раздела, чувствительные данные скрываются существующим редактором.
Список установленных приложений в TV-сборке учитывает оба launcher: обычный и
Leanback. Прямой обход приложений остаётся ограничен существующим allowlist,
неизвестные пакеты не добавляются по префиксу автоматически.

## Сборка

Нужны Flutter SDK, Android SDK/NDK, JDK 17 и локальный `android/key.properties`
с release-подписью. Файл ключей нельзя публиковать.
JNI CMake-метаданные хранятся локально в `android/.cxx/jni`, а не в общем Pub-кэше;
это исключает использование путей от другой рабочей копии проекта.

```powershell
$env:JAVA_HOME = 'C:\Program Files\Eclipse Adoptium\jdk-17.0.19.10-hotspot'
$env:GRADLE_USER_HOME = 'D:\Yurich Connect\.gradle'
.\tooling\build_tv.ps1 -FlutterSdk 'D:\FlutterSDK'
```

Скрипт проверяет анализатор и Flutter-тесты, собирает release APK для ARM32/64,
проверяет наличие Flutter, sing-box, Xray и JNI для обеих архитектур,
сохраняет его в `build/tv` и выводит SHA-256. При использовании другой версии JDK
нужно указать её фактический путь.

Системная Activity выбирает Dart entry point `tvMain` по flavor, поэтому отдельный
флаг Dart или альтернативный `main.dart` не нужен. Баннер TV находится в
`android/app/src/tv/res/drawable-xhdpi/tv_banner.png` (320 x 180 px).

```powershell
& 'D:\FlutterSDK\bin\flutter.bat' test test/tv_home_screen_test.dart --no-pub --dart-define=WRITE_TV_ASSETS=true
```

Эта команда обновляет баннер штатным Flutter-рендерером и сохраняет контрольные
снимки интерфейса в `build/qa/android-tv-20261003`. Тестовые профили синтетические.

## Установка И Обновления

Установить подписанный TV APK через системный установщик. При первом подключении
подтвердить информационное согласие приложения и системный запрос VPN.
Для отладки можно использовать ADB только после явного разрешения на приставке.

TV использует тот же package ID `online.dnsai.ivanvpn`. Не удалять уже установленное
приложение перед обновлением: подпись должна совпадать, versionCode новой сборки
должен быть выше установленного. TV и телефонный APK заменяют друг друга на одном
устройстве, а не устанавливаются как два независимых приложения.

Канал `tv` не скачивает телефонный APK и не предлагает Google Play. Пока нет
отдельно опубликованного канала TV-обновлений, обновление выполняется вручную
TV APK из GitHub Releases. Ссылка в приложении открывает страницу релизов;
сама по себе она не означает, что TV APK уже опубликован.

Первый предварительный TV-релиз: `1.0.128-tv.20261003.1`, versionCode `43141`.
[Описание и контрольная сумма APK](releases/v1.0.128-tv.20261003.1.md).
Комплект фотографий, текста и APK собирается отдельно по
[инструкции публикации](TV_PUBLICATION.md).

Возврат к прежнему интерфейсу без потери профилей: собрать нужный flavor из
проверенного исходного состояния с той же подписью и более высоким versionCode,
затем установить поверх. Не удалять данные и не применять сброс устройства.

## Проверка На Приставке

1. Запуск из Android TV launcher, импорт новой подписки, согласия VPN.
2. Управление только пультом, длинный список, фильтры, ввод и «Назад».
3. Каждый поддерживаемый протокол: внешняя HTTPS/DNS-проверка, браузер/видео,
   ненулевые счётчики при трафике, переключение профилей.
4. Smart Route и Auto DNS, Wi-Fi/Ethernet, потеря сети и восстановление.
5. Сон, выключение экрана, возврат из другого приложения и длительная работа.

Widget-тесты и успешная сборка не подтверждают пропускную способность,
24/7 стабильность или совместимость конкретной операторской прошивки.

Официальные требования: [TV app](https://developer.android.com/training/tv/get-started/create),
[навигация пультом](https://developer.android.com/training/tv/get-started/navigation).
