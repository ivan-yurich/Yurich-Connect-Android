## Как читать колонку Smart Route

Сверка с каталогом Yurich Connect на момент расширения до 101 точного ID.
Позднее в `.19` все [24 строки «Нет» из двух топов](SMART_ROUTE_RU_RUSTORE_TOP_2026-11-12.json)
добавлены в каталог (всего 125). Таблица ниже сохраняет исходный срез;
дополнительные 28 и правила для браузеров этим изменением не затрагивались.

- **Каталог** — 17 позиций из среза; доступны в выборе приложений, часть также
  имеет старое встроенное правило. Старое правило может действовать независимо от галочки.
- **Встроено** — ещё 13 позиций, уже есть отдельное правило по пакету, но
  не строка выбора в каталоге. Условия применения маршрута по-прежнему действуют.
- **Только домены** — 3 универсальные оболочки. Весь браузер не направляется
  напрямую; решение принимается по известному адресу сайта.
- **Нет** — 24 без правила по пакету. Это не означает отсутствия правила для
  официального сайта; список не включает эти пакеты автоматически.

## Яндекс, Mail и веб-поиск

[Яндекс](https://ya.ru/) уже покрыт доменными правилами, как и [портал Mail](https://mail.ru/).
Отдельный действующий поиск по `go.mail.ru` не подтверждён: при проверке адрес
перенаправил на вход к порталу Mail. Из других общих российских поисков
подтверждён [Рамблер/поиск](https://r0.ru/). Добавлены его точные поисковые адреса:
`r0.ru`, `nova.rambler.ru`, `images.rambler.ru`, без правила для всех поддоменов Рамблера.
Сторонние сайты в [Yandex Cloud](https://yandex.cloud/ru/docs/storage/concepts/hosting)
больше не становятся прямыми только из-за общего суффикса `yandexcloud.net`.

## Что реально изменилось в каталоге

Ранее согласованное расширение: 48 новых записей (45 подтверждены в RuStore,
3 — в Google Play). [Полный список новых ID и источников](SMART_ROUTE_RU_CATALOG_EXPANSION_2026-11-12.json).
Ручные отметки сохраняются при обновлении; новые позиции отмечаются автоматически
только в режиме настроек каталога по умолчанию. При строгом Kill Switch
исключения для целых приложений не применяются. Аудит двух топов сам по себе
не меняет маршрутизацию.
