Текст готов для GitHub Release, но наличие этих файлов не означает публикацию.
Оригинальные фотографии, подписки, локальная диагностика и ключи подписи
не должны попадать в публичный Git или архив релиза.

## Архив

```powershell
.\tooling\package_tv_publication.ps1
```

Скрипт не собирает приложение повторно и не обращается к GitHub. Он проверяет
SHA-256 готового TV APK и PNG, создаёт комплект из явного списка файлов,
добавляет контрольные суммы и проверяет содержимое готового ZIP.
Файлы не удаляются и не перезаписываются: повторный запуск требует нового имени.
В PNG нет перенесённого EXIF исходных фотографий. Проверенные метаданные
происхождения редактора C2PA сохранены; они не выдаются за личные данные.

Результат: `build/publication/YurichConnect-TV-publication-v1.0.128-tv.20261003.1.zip`.
Внутри находятся APK, шесть обработанных иллюстраций, текст релиза, инструкции,
галерея, манифест и `SHA256SUMS.txt`. Исходный код, ключи и приватные QA-отчёты
в архив не включаются. Архив удобен для передачи комплекта; установка производится
из APK, а не из ZIP.
Файл `README-GITHUB-FRAGMENT.md` содержит готовый TV-раздел для страницы проекта,
`RELEASE-BODY.md` и `RELEASE-TITLE.txt` предназначены для формы GitHub Release.

## Размещение На GitHub

1. Просмотреть галерею и убедиться, что личные данные нигде не читаются.
2. Внести в репозиторий только проверенные исходники TV-версии, документацию
   и обработанные изображения. Не добавлять весь `build` или рабочую папку.
3. Создать отдельный предварительный релиз с тегом `v1.0.128-tv.20261003.1`
   на проверенном коммите TV-версии. Заголовок: `Yurich Connect TV 1.0.128 - Preview`.
4. Использовать текст из `docs/releases/v1.0.128-tv.20261003.1.md` как описание;
   отметить релиз как **pre-release**, не делать его основным телефонным релизом.
5. Прикрепить TV APK и `assets/SHA256SUMS.txt` из комплекта.
   ZIP можно добавить отдельно для передачи всей галереи и документации.

Не переименовывать TV APK в `YurichConnect-android-release.apk`:
телефонный канал обновлений не должен принять TV-сборку за мобильную.
Фотографии в галерее обработаны генеративным редактором и не служат
подтверждением работы внешнего интернета или стабильности 24/7.

## Проверка И Откат

После публикации проверить скачивание именно TV APK, его SHA-256 и открытие
всех изображений на странице проекта. Сетевые и длительные проверки на приставке
выполнять по [чек-листу](ANDROID_TV.md#проверка-на-приставке).

Для изменения публичного текста отредактировать документы отдельным коммитом.
При ошибке в APK не удалять данные пользователей: подготовить исправленный TV APK
с прежним сертификатом и большим versionCode. Не использовать телефонную сборку
как автоматическую замену TV и не публиковать неподтверждённые обещания стабильности.
