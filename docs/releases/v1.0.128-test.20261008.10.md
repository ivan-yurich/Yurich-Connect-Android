# Yurich Connect Android 1.0.128-test.20261008.10

Тестовый prerelease для телефона, 8 октября 2026 года.
GitHub-канал, ARM64, Android versionCode `43151`.

> Обновлён механизм получения обновлений. Это не стабильный сетевой релиз:
> ранее выявленные отказы Hysteria2/Reality и причины двух SIGKILL ещё исследуются.
> Stable 1.0.127 и TV preview не заменяются.

## Что Изменилось

- Сборки с версией `1.0.x-test.YYYYMMDD.N` получают новые опубликованные
  Android prerelease из последних двадцати GitHub Releases. Стабильные сборки
  продолжают проверять только стабильный latest и существующий резервный источник.
  Токен GitHub не нужен и не встраивается в приложение.
- Полная версия сравнивается по основному номеру, дате и числовому номеру теста:
  `.10` новее `.9`, суффикс больше не отбрасывается. Финальная стабильная версия
  того же основного номера имеет приоритет; после её установки используется
  стабильный канал.
- Скачивание сохраняет точный тег выбранного релиза. Нет подмены prerelease
  ссылкой на stable/latest. Каталог кэша включает полную тестовую версию.
- Выбираются только известные имена телефонных APK для доступной ABI;
  TV, черновики, чужие имена и незавершённые загрузки исключаются.
  Общие старые имена опубликованного телефонного APK используются только на ARM64.
- До установки версия скачанного APK сверяется с выбранным релизом.
  Сохранены проверки package, подписи установленного приложения и строго
  возрастающего Android versionCode. Совпадение названия релиза не заменяет
  проверку APK; меньший или равный versionCode отвергается.
- Автоматическая проверка выполняется при запуске и возврате в приложение,
  не чаще одного раза за шесть часов в рамках процесса. Используется монотонное
  время; одновременно начатые ручная и автоматическая проверки делят запрос.
  Уведомление показывается один раз для каждой обнаруженной версии.
- В настройках тестового APK канал обозначен как «GitHub / Тестовый».
  TV, Google Play и soak не получают телефонные APK через этот механизм.

Автоматически обнаруживается обновление, но скачивание начинается по нажатию
пользователя. Установку подтверждает системный установщик Android.
Обновлятор не запускает фоновый таймер, wake lock или скрытую установку.
Если приложение всё время закрыто, новая проверка произойдёт при его следующем
запуске/возврате, а не по расписанию в фоне.

Подписки, профили, API, маршрутизация, DNS и VPN-ядра в этом изменении не меняются.
Шесть часов отсчитываются от последней попытки, включая ошибки и ручную проверку;
ручную проверку можно повторить без ожидания этого интервала.

## Первый Переход

Старые версии, включая `.9`, проверяют только stable/latest. Они не могут
обнаружить этот prerelease через старый обновлятор.

1. Скачайте `YurichConnect-android-arm64-v8a-v1.0.128-test.20261008.10.apk` из Assets.
2. Установите поверх GitHub-сборки с той же подписью. Не удаляйте приложение,
   не очищайте данные и профили.
3. Откройте приложение. Канал обновлений будет «GitHub / Тестовый».
4. Следующие новые совместимые тестовые версии будут обнаруживаться новым
   обновлятором без отдельного посещения страницы GitHub.

Требуются Android 7.0 / API 24 и ARM64 (`arm64-v8a`),
package `online.dnsai.ivanvpn`, versionCode `43151`. Это не TV APK и не Play AAB.
Если `.10` уже установлена, уведомление о ней повторно не показывается.

APK: 47 000 783 байта. Подпись повторно проверена `apksigner`.

SHA256 APK:

```text

```

SHA256 сертификата подписи:

```powershell

if ((Get-FileHash -LiteralPath $apk -Algorithm SHA256).Hash.ToLowerInvariant() -ne $expected) {
    throw 'APK checksum mismatch'
}
```

## Проверки И Ограничения

Добавлены регрессии для тестового и стабильного каналов, порядка версий,
исключения TV/draft, выбора ABI, отдельных кэшей, совместного запроса,
частоты уведомлений и точной версии APK перед установкой.

8 октября прошли **212 Flutter-тестов**, статический анализ завершился без
замечаний. Проверки используют локальные HTTP-фикстуры и не подменяют испытание
системного установщика на подключённом Android-устройстве.

Нативные исходники не менялись относительно `.9`; сохранённый результат
Kotlin: 156 тестов без ошибок. Сетевые результаты `.9` (27/32 переключений,
8/8 Chrome, пять readiness-отказов и два SIGKILL) не выдаются за новый прогон `.10`.
Подробности: [предыдущий отчёт релиза](v1.0.128-test.20261007.9.md).

Новая сборка не доказывает стабильность 24/7 и не устраняет ранее найденные
проблемы протоколов. Перед стабильным релизом остаются их разбор и повторная
проверка на телефоне. GitHub API может быть временно недоступен или ограничен
по частоте запросов; для тестового канала это ошибка проверки, а не подмена
ссылки на другую версию.

## Разработка И Откат

Команды из каталога проекта при настроенных Flutter, Android SDK и JDK 17:

```powershell
flutter analyze --no-pub
flutter test --no-pub
flutter build apk --release --flavor github --target-platform android-arm64 --split-per-abi --build-name 1.0.128-test.20261008.10 --build-number 41151 --no-pub
```

ARM64 split даёт versionCode `43151`. Для установки поверх официальной сборки
нужен тот же локальный keystore. Ключи, `.env`, подписки и личные логи не публикуются.

Для отката без удаления данных пересоберите предыдущие известные исходники
в отдельном рабочем дереве тем же ключом с versionCode больше `43151`,
например ARM64 `--build-number 41152` даёт `43152`. Не сбрасывайте локальные
изменения и не удаляйте приложение ради отката без безопасной копии профилей.
