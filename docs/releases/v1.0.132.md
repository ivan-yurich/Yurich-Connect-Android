# Yurich Connect 1.0.132 — Android

Обновление стабильного канала GitHub для телефонов ARM64 с Android 7.0 и новее.
Состояние системной блокировки Kill Switch и выбор приложений Smart Route
поддерживаются начиная с Android 10.

## Что изменилось

- Новый экран подключения: крупная кнопка VPN, компактная карточка локации,
  единый список серверов и обновлённая форма добавления подписки.
- «Авто» может выбрать другую локацию после сбоя подключения. Отмена и смена
  профиля завершают предыдущую попытку; улучшено восстановление при переходе
  между Wi-Fi и мобильной сетью.
- Введены понятные статусы доступности серверов и показ приёма/отдачи в
  уведомлении. Прямой замер без VPN и без Kill Switch — только по согласию.
- Smart Route отправляет напрямую только известные сервисы и выбранные
  приложения (в том числе есть 2ГИС, Mir Pay и VK Музыка). Новые установки
  Android 10+ получают включённый каталог с предупреждением о прямом трафике;
  при обновлении прежний выбор сохраняется. Браузеры целиком не исключаются.
- Строгий Kill Switch опирается на системные «Постоянная VPN» и «Блокировать
  соединения без VPN». Прямые исключения в этом режиме не применяются.
- Профили с неподдерживаемым закреплением TLS-сертификата отклоняются.
  Для отдельных старых конфигураций потребуется вручную запустить подключение.

## Как обновиться

Откройте «Настройки → Приложение и поддержка → Проверить обновления» либо
установите `YurichConnect-android-release.apk` поверх официальной GitHub-сборки.
Не удаляйте приложение: обновление рассчитано на сохранение профилей и настроек.
APK с другой подписью (например, самостоятельно собранный или из другого канала)
нельзя обновить поверх этим файлом. Не обходите проверку подписи.

Стабильная версия: `1.0.132`, Android versionCode `43210`, package
`online.dnsai.ivanvpn`. Проверки релиза не гарантируют стабильность 24/7
на всех устройствах, сетях и подписках.

Статический анализ без замечаний, 432 Flutter-теста прошли, 4 пропущены.
Проверены подпись, ARM64, minSdk 24 и совпадение package с 1.0.131. При
необходимости отката без очистки данных соберите предыдущие известные исходники
тем же ключом с versionCode выше `43210`. Прямая установка APK с меньшим
versionCode поверх нового не поддерживается.
