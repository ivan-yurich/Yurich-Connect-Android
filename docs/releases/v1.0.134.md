# Yurich Connect 1.0.134 — Android

- «Авто» пробует сервер на подтверждённом маршруте LTE, даже если общая проверка интернета Android ещё не прошла. Неопределённый маршрут по-прежнему не используется для старта VPN.
- Подписки обновляются раз в два часа, пока Android даёт приложению работать. Если система приостановила процесс, приложение проверит пропущенный срок при возобновлении.
- Обновление подписки сохраняет текущий активный профиль и не перезапускает VPN. Проверки TLS и Kill Switch не изменились.

Для обновления устанавливайте подписанный Android APK поверх предыдущего приложения — удалять его не нужно. APK предназначен для ARM64; ожидаемый versionCode — 43217. Android попросит подтвердить установку.
