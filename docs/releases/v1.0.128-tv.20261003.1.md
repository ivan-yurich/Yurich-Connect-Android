# Yurich Connect TV 1.0.128

Предварительный релиз для Android TV / Google TV · 3 октября 2026 года

Yurich Connect выходит на большой экран. TV-версия получила отдельный интерфейс
для пульта, сохранив VPN-ядро, подписки и настройки сети мобильного приложения.
Для подключения нужна действующая подписка или собственный совместимый сервер.

## Что Нового

- Горизонтальный интерфейс с крупными элементами и видимым фокусом пульта.
- Переключение профилей, фильтры протоколов и прокрутка длинных списков.
- Импорт подписки с экранной клавиатуры или из буфера обмена по действию пользователя.
- Подключение и отключение, время сеанса и счётчики трафика.
- Smart Route, Auto DNS, выбор языка, логи и политика конфиденциальности.
- Плитка приложения в Android TV launcher и отступы для overscan.
- Возврат из настроек и выход из интерфейса не отключают VPN сами по себе.
- Отдельная ARM32/ARM64-сборка; обновление только TV APK, без подмены телефонной версией.

## Протоколы И Маршрутизация

| Технология | Назначение |
| --- | --- |
| VLESS Reality | TCP-подключение с параметрами из профиля |
| NaiveProxy | HTTPS-прокси, в том числе для сетей с недоступным UDP |
| Hysteria2 | QUIC/UDP при поддержке со стороны сети и сервера |
| VLESS XHTTP | Экспериментальный транспорт через совместимый Xray; TLS или Reality |

Smart Route применяет существующие списки доменов и разрешённых приложений.
Известные российские сервисы могут идти напрямую, остальные направления остаются
в VPN. Прямые сервисы видят IP оператора. Auto DNS управляет DNS внутри
VPN-конфигурации; NaiveProxy сохраняет локальный bootstrap DNS для адреса сервера.
Абсолютное отсутствие любых DNS-запросов вне туннеля во всех режимах не заявляется.

## Совместимость И Установка

- Android TV / Google TV на Android 7.0 / API 24 или новее.
- Архитектуры `armeabi-v7a` и `arm64-v8a`; x86/x86_64 не поддерживаются этим APK.
- Нужны доступный Android VpnService, системный установщик и разрешение на VPN.
- Закрытые операторские прошивки и YaOS не гарантируют установку и работу VPN.

1. Установите `YurichConnect-TV-arm-v1.0.128-tv.20261003.1.apk` через системный установщик.
2. Откройте Yurich Connect TV из списка приложений.
3. Добавьте свою подписку, выберите профиль и подтвердите запрос Android на VPN.
4. Проверьте сайт или видео в другом приложении: одного статуса или счётчика недостаточно.

APK подписан тем же сертификатом, что и Android release-сборки проекта.
Package `online.dnsai.ivanvpn` общий: TV и телефонная версии заменяют друг друга
на одном устройстве. Не удаляйте приложение перед обновлением.
Обновление TV пока ручное; публикация в Google Play не заявляется.

## Проверки И Ограничения

При подготовке этой сборки 3 октября выполнены:

| Проверка | Результат |
| --- | --- |
| Flutter analyzer | Без замечаний |
| Flutter | 179 тестов прошли, включая 19 TV-тестов |
| Android / Kotlin | 118 тестов прошли, без ошибок и пропусков |
| Комплектация APK | Flutter, sing-box, Xray и JNI проверены для обеих ARM-архитектур |
| Подпись APK | Проверка apksigner успешна |

TV-тесты охватывают фокус пульта, длинный список, импорт, возврат из логов,
разные размеры экрана и увеличенный системный текст. Они не измеряют скорость сети.
Получены пользовательские фотографии установленного приложения на приставке;
для публичной галереи выполнены кадрирование, генеративная ретушь и скрытие личных данных.

Внешние HTTPS/DNS-запросы, все серверы и протоколы, переключение Wi-Fi/Ethernet,
сон, температура и длительная работа на физической приставке пока не подтверждены
отдельным тестом. XHTTP остаётся экспериментальным. Сборка предназначена для
предварительного тестирования, а не как гарантия непрерывной работы 24/7.
