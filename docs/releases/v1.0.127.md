# Yurich Connect 1.0.127

Android APK · GitHub distribution · build 43139 · 2026-09-30

## Изменения С 1.0.124

- Hysteria теперь отображается как **ИИ**, NaiveProxy как **Веб**. Технические идентификаторы и сохранённые профили не менялись.
- TLS-XHTTP больше не подписывается как generic vless или Reality-XHTTP. Список, статус и диагностика учитывают transport/security профиля.
- Анимация, UI-таймер и перерисовка скрытого экрана приостанавливаются в фоне. Нативные проверки VPN и уведомления продолжают работать.
- Улучшено размещение панели подключения и заголовка на узких экранах.
- Smart Route использует явный список приложений для прямого маршрута; неизвестные пакеты `ru.*` остаются в VPN.
- Импорт подписки ограничен общим таймаутом 45 с; просроченные HTTP-запросы отменяются.
- Загрузчик APK прерывает зависшую загрузку, разделяет кэш по версиям, проверяет имя файла и использует только явно разрешённые ссылки из метаданных.
- DNS-индикатор Hysteria больше не выдаёт успешное разрешение имени за подтверждение доступности UDP/QUIC.
- Убрано ложное подтверждение готовности runtime при недоступной локальной проверке; для raw sing-box конфигураций добавлен локальный health proxy. Запуск произвольного JSON из пользовательского интерфейса по-прежнему не заявляется.

Во время восстановления XHTTP watchdog штатно перезапустил native VPN-процесс и подтвердил готовность внешними проверками. Это не вылет приложения, но восстановление не мгновенное. Счётчик после перезапуска вновь увеличивался.

В проверенных exit-info и crash-логах текущего прогона не обнаружено CRASH/ANR приложения. Короткие проверки не подтверждают стабильность 24/7, все серверы подписки, все операторы или все прошивки. XHTTP остаётся экспериментальным. Телефон заряжался через USB; энергопотребление не оценивалось.

## Ограничения И Откат

Smart Route намеренно допускает прямой трафик известных сервисов; Веб сохраняет локальный bootstrap DNS. Приложение не заявляет отсутствие любых DNS-запросов вне VPN во всех режимах.

Android обычно запрещает установку предыдущего versionCode поверх нового. Для отката без удаления данных требуется подписанная сборка предыдущих исходников с увеличенным versionCode. Не удаляйте приложение ради отката без резервного сохранения профилей в безопасном месте.
