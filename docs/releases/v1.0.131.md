# Yurich Connect Android 1.0.131

Обновление обычного GitHub-канала, 23 октября 2026 года.
Android 7.0 / API 24+, ARM64, package `online.dnsai.ivanvpn`, versionCode `43158`.

## Исправление доставки обновлений

Версия `1.0.127` проверяет GitHub `releases/latest`. Предыдущий опубликованный
`1.0.131-test.20261023.1` находился в тестовом канале, а Latest продолжал возвращать
`1.0.127`. Поэтому обычный клиент сообщал об отсутствии обновлений.

Для обычного канала собрана отдельная APK с полной версией `1.0.131`,
возрастающим Android versionCode `43158` и прежней подписью. Тег релиза и версия
APK совпадают. Этот релиз выбран GitHub Latest и содержит совместимый asset
`YurichConnect-android-release.apk` для встроенного обновлятора и основной
кнопки скачивания. Он идентичен `YurichConnect-android-arm64-v8a-v1.0.131.apk`.

## Изменения приложения

- Hysteria2 на мобильной сети: одна мягкая попытка восстановления после
  подтверждённого сбоя; повторная проверка и ограниченный полный restart при
  необходимости. Таймер Reconnecting не пропускает мягкую попытку.
- Сохранение счётчиков при нативном recovery и пересоздании Flutter; корректная
  обработка временного нуля, сбросов и смены источника UID/sing-box.
- Освобождение ресурсов native-клиента после неудачного подключения и защита
  новой сессии от устаревших callbacks.
- Проверки VPN с deadline, отменой отстающих сокетов и ограниченным wake lock;
  упорядочены события сети, смена ядра и восстановление после обновления APK.
- Убрана постоянная пульсация главного экрана.
- Исправлены зависшие проверки обновлений, повторные попытки и взаимодействие
  с системным установщиком Android 15/16.
- Улучшены локальная диагностика, экспорт и анализ счётчиков разных процессов.
- VLESS без TLS/Reality теперь отклоняется при импорте и построении конфигурации.
  Существующие профили не удаляются; для незащищённых VLESS нужен новый профиль
  от провайдера. В ошибку импорта не включается исходная ссылка с credentials.

Runtime соответствует кандидату `1.0.131-test.20261023.1` (`43157`). Изменены
версия и сведения о публикации; VPN-ядра не обновлялись. Подробное описание
исправлений: [заметки кандидата](v1.0.131-test.20261023.1.md).

## Проверки и ограничения

- 233 Flutter, 203 Kotlin и 118 Python-тестов прошли.
- Статический анализ Flutter и Android release lint успешны.
- Подпись, package, версия, versionCode и ARM64 проверены в готовой APK.
- Три проверки совместимости прошли с неизменённым исходным обновлятором
  опубликованной `1.0.127`: обнаружение новой версии и выбор ARM64, новый stable
  parser и проверка возрастающего versionCode при совпадающей подписи.

Суточное испытание предыдущей soak-сборки `43156` на телефоне ещё идёт.
У неё прошли 12/12 HTTPS-проверок cellular после обновления, но эти проверки
не подтверждают непрерывную работу 24/7. В исходном отчёте `43155` сохранялись
отказы Hysteria2/cellular; эффективность новых мер требует длительного подтверждения.
Полная матрица всех профилей и протоколов этим выпуском не сертифицирована.

Получение метаданных и доступность скачивания проверяются со стороны GitHub
и исходного клиента; системная установка `43158` на телефоне в этой сессии
не проверена.

## Установка

1. В `1.0.127` откройте настройки и нажмите «Проверить обновления».
2. Подтвердите загрузку `1.0.131`, при необходимости разрешите установку из
   Yurich Connect и повторите установку.
3. Если старый установщик не открывается, скачайте APK из Assets браузером
   и установите поверх приложения. Удалять приложение или данные не требуется.

Требуются Android 7.0+ и ARM64. TV, Play и soak сохраняют свои каналы.
Сертификат подписи SHA-256:

```text
8e2f739b93e8081afccca276a4fe9d282d3acec30988813e0d24bf59963ba746
```

Контрольные суммы обеих идентичных APK находятся в `SHA256SUMS.txt` и
[копии в исходниках](v1.0.131-SHA256SUMS.txt). SHA-256 APK:

```text
8718ca2b347a78cdc383bb2e72673863d50e6f964217072e3e1de43483616d6d
```

## Сборка и откат

```powershell
flutter build apk --release --flavor github --target-platform android-arm64 --split-per-abi --build-name 1.0.131 --build-number 41158 --no-pub
```

Для отката без потери данных нужна сборка предыдущих исходников с той же подписью
и versionCode выше `43158`; например, ARM64 `--build-number 41159` даёт `43159`.
Не удаляйте приложение ради установки старого APK.
