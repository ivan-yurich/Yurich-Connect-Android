# Yurich Connect Android 1.0.131-test.20261023.1

Тестовое обновление для телефона от 23 октября 2026 года.
GitHub-канал, ARM64, Android 7.0 / API 24+, versionCode `43157`.

Обновление улучшает восстановление VPN, учёт трафика и установку новых APK.
Длительная проверка Hysteria2 на мобильной сети продолжается; релиз опубликован
в тестовом канале. Стабильный 1.0.127 и отдельная TV-версия сохраняют свои каналы.

## Что сделали

- Hysteria2/cellular: после первого подтверждённого сбоя периодического
  health-check выполняются мягкие `resetNetwork()` и `wake()`. Затем проверка
  повторяется через 12 секунд (30 секунд в Doze); полный restart остаётся после
  второго неуспешного цикла. Мягкая попытка доступна только ранее готовому
  туннелю и ограничена одной на readiness-job; первоначальный запуск её не вызывает.
  Новый таймер фазы Reconnecting больше не пропускает эту попытку.
- Проверки сети: общий deadline 12 секунд, раннее завершение по результату
  2 из 3, отмена оставшихся сокетов и readiness wake lock максимум 15 секунд.
  Повторные проверки отделены от backoff полного перезапуска.
- Счётчики: сохранение сессии при пересоздании Flutter и автоматическом recovery;
  нормализация сбросов native-провайдера, смены UID/sing-box и кратковременного нуля.
  Явное новое подключение начинает новую сессию. Показания не используются для биллинга.
- Native-клиенты: закрытие ресурсов после неудачного подключения и защита от
  запоздавших callbacks предыдущего поколения.
- Фоновая работа: упорядочены сетевые callbacks, исключён собственный package
  из VPN-маршрута, добавлена защита от подтверждённого FD pressure. Чистая смена
  ядра завершается независимо от зависшего native teardown.
- Обновление APK: ограниченное восстановление после package replace, отмена
  зависших запросов метаданных, отдельный лимит источника 12 секунд и корректные
  ошибки неизвестной ABI/недоступной testing-ленты. Улучшен запуск установщика
  Android 15/16; проверки package, подписи, версии и versionCode сохранены.
- UI: убрана постоянная пульсация главного экрана; сохранены счётчики во время
  нативного восстановления и остановка лишнего опроса скрытого экрана.
- Диагностика: сети и probe-id связываются с quorum, учитываются CPU/FD/threads,
  thermal и native/display counters. У счётчиков появился `instanceMs`, поэтому
  анализатор различает повторно использованные PID разных процессов.
- Для soak-сборки добавлен пассивный 24-часовой режим на телефоне с проверенным
  экспортом ZIP. Пользователь может пользоваться телефоном и менять сеть сам;
  публичная GitHub APK содержит стандартную пользовательскую диагностику.

## Совместимость

VLESS без TLS/Reality теперь отклоняется при импорте URI, sing-box/Xray JSON
и построении конфигурации. Для таких профилей требуется защищённый вариант
на стороне провайдера. Уже сохранённые профили не удаляются.
Сообщение ошибки импорта больше не содержит исходную ссылку с credentials.

API подписок и формат хранения профилей сохранены. Добавлены приватные checkpoint
счётчиков и поля локальной диагностики; миграция серверной БД не требуется.
VPN-ядра не обновлялись: sing-box/libbox `1.13.11`, существующий Xray.

## Установка

Скачайте из Assets `YurichConnect-android-arm64-v8a-v1.0.131-test.20261023.1.apk`
и установите поверх официальной GitHub-сборки с той же подписью. Профили и
настройки сохраняются. Package: `online.dnsai.ivanvpn`, versionCode: `43157`.

Тестовые клиенты с обновлятором из `.10` обнаружат релиз через меню обновления.
Stable/TV/Play используют свои каналы. Soak-сборка на тестовом телефоне не
обновляется автоматически; для непрерывности теста её пока оставляем установленной.

## Сборка и откат

```powershell
flutter analyze --no-pub
flutter test --no-pub
.\android\gradlew.bat -p android :flutter_singbox_vpn:testDebugUnitTest
python -m unittest discover -s tooling/soak -p 'test_*.py'
python -m unittest tooling.test_analyze_device_diagnostics
flutter build apk --release --flavor github --target-platform android-arm64 --split-per-abi --build-name 1.0.131-test.20261023.1 --build-number 41157 --no-pub
```

Для отката с сохранением данных пересоберите известные предыдущие исходники
тем же ключом с versionCode выше `43157`; например, ARM64 `--build-number 41158`
даёт `43158`. Не удаляйте приложение и не очищайте данные ради отката.
Мягкий сетевой reset способен кратко прервать потоки при уже подтверждённой
деградации Hysteria2/cellular; его эффективность проверяется новым суточным тестом.
